# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Desktop и ядро версионируются отдельно; для каждого выпуска фиксируется engine.lock.json.

## [Unreleased]

Будущие изменения добавляются сюда вместе с реализацией и подтверждёнными проверками. Планы находятся в roadmap и не считаются выпущенными возможностями.

## [0.1.0-beta.4] - 2026-10-14

- «Настройки → Расширения»: общий каталог builtins/user packages, поиск/фильтры, сведения, фактические статусы и разрешённые действия. Системный выбор папки/ZIP, review с неотмеченным trust, update, версии/rollback, disable/remove используют единственный core PackageManagementService.
- Реальные формы LSP, субагентов и фоновых задач через публичный SDK/core stores; декларативные параметры внешних пакетов, defaults/validation, защищённые секреты и сохранение неизвестных значений.
- Явный перезапуск с проверкой активных задач/очереди. Черновики и выбранная беседа сохраняются при перезапуске; review очищается через core при закрытии. Обе темы и компактное окно сохраняют прежнее оформление и видимый фокус.
- Встроен опубликованный [ChiselCode 0.6.30](https://github.com/TheAsrada/ChiselCode/releases/tag/v0.6.30), source `9f3858c0d67bf8a0ccc0c22ca6bcec3829a8002a`, protocol 1.1 / SDK 1.1.0. Lock закрепляет настоящие engine/SDK/skills и SHA-256; прежние пакеты SDK API v1, общие профили и Session schema 3 совместимы.

- В AGENTS.md закреплена обязательная проверка документации при каждом задании: соответствие коду, единый стиль, структура по задачам читателя, оглавления, ссылки и примеры. Правила согласованы с CLI и доступны из оглавления документации; README уточнён для текущей beta.

## [0.1.0-beta.3] - 2026-10-14

### Изменено

- Из окна «Подтвердить действие» удалены оранжевый щит и его подложка. Рядом с версией ядра удалена зелёная точка; номер версии остаётся видимым.
- В AGENTS.md закреплён общий с CLI порядок изменений, обновления engine/SDK и выпуска обеих оболочек по просьбе владельца. Документация различает локальную интеграцию, ожидающий core release и опубликованные установщики.
- Новое оформление по визуальным референсам владельца: дымчатая основа, плавающие панели, навигационная капсула, собственный гранёный знак Chisel и variable Manrope. Светлая тема используется при первом запуске; сохранённые светлая/тёмная/системная настройки сохраняются.
- Обновлены главный экран, беседа, карточки инструментов, diff, поле ввода, настройки и подтверждения. Быстрые действия явно выбирают Plan/Build; навигация сохраняет черновик, компактный inspector закрывается отдельной кнопкой.
- В подтверждении точная текстовая копия уже показанного diff не дублируется; отдельные пояснения операции и команда сохраняются.
- Реальный GUI acceptance проверяет переключение и сохранение темы, быстрые действия, навигацию и доступность поля ввода в уменьшенном окне. Добавлены настоящие кадры светлой/тёмной тем, компактного окна и настроек. Общий engine остаётся ChiselCode 0.6.29.
- Проверка установленных payload выбирает установщики текущей версии и native architecture; оставшиеся в локальной папке файлы прежних выпусков больше не подменяют проверяемую сборку.

Ядро: ChiselCode 0.6.29, protocol 1.0; формат общих сессий и профилей сохранён. Windows остаётся без подписи издателя, macOS — ad-hoc без notarization.

## [0.1.0-beta.2] - 2026-10-14

Первый опубликованный beta-выпуск. Тег beta.1 был промежуточным; релиз с ним не публиковался.

### Добавлено

- Первый самостоятельный desktop-клиент ChiselCode: проекты, беседы, потоковый Markdown, код и карточки инструментов.
- Интерфейс без слоганов и постоянных поясняющих подсказок; короткие действия, состояния операций и данные проекта.
- Подтверждение действий с настоящим diff, отказ, отмена, очередь сообщений и общая история с CLI.
- Настройка общих профилей моделей, Git-панель, каталог навыков и команд, подключение MCP HTTP/stdio.
- Панель состояний помощников/фоновых задач, тёмная/светлая/системная темы, горячие клавиши и уведомления.
- Автономное ядро из ChiselCode, типизированный SDK, согласование версии протокола и проверяемый engine.lock.json.
- Первый выпуск закреплён на ChiselCode 0.6.29: общий runtime, session schema 3 и protocol 1.0, live background output/stop и сохранённые результаты команд.
- Установщики Windows x64, macOS arm64/x64 и Linux x64; процесс проверки обновлений.
- Архитектурные решения, инструкция обновления ядра, документация установки и выпуска, реальные GUI/engine acceptance.

### Ограничения beta

- Подписи издателя Windows и нотариального заверения Apple пока нет; macOS использует ad-hoc подпись.
- Побочные вопросы `/btw`, произвольные extension UI contributions и расширенные формы LSP пока доступны через терминальный интерфейс.
- Графические действия для сохранённых помощников и подробного вывода фоновых задач требуют следующего этапа. Их состояние и результаты core-инструментов доступны в беседе.
- Параллельные linked worktrees в разных процессах используют общий консервативный допуск Git.
