Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Desktop и ядро версионируются отдельно; для каждого выпуска фиксируется engine.lock.json.

Будущие изменения добавляются сюда вместе с реализацией и подтверждёнными проверками. Планы находятся в roadmap и не считаются выпущенными возможностями.

## [0.1.0-beta.1] - 2026-10-14

### Добавлено

- Первый самостоятельный desktop-клиент ChiselCode: проекты, беседы, потоковый Markdown, код и карточки инструментов.
- Подтверждение действий с настоящим diff, отказ, отмена, очередь сообщений и общая история с CLI.
- Настройка общих профилей моделей, Git-панель, каталог навыков и команд, подключение MCP HTTP/stdio.
- Панель состояний помощников/фоновых задач, тёмная/светлая/системная темы, горячие клавиши и уведомления.
- Автономное ядро из ChiselCode, типизированный SDK, согласование версии протокола и проверяемый engine.lock.json.
- Первый выпуск закреплён на ChiselCode 0.6.29: общий runtime, session schema 3 и protocol 1.0, live background output/stop и сохранённые результаты команд.
- Установщики Windows x64, macOS arm64/x64 и Linux x64; процесс проверки обновлений.
- Архитектурные решения, инструкция обновления ядра, документация установки и выпуска, реальные GUI/engine acceptance.

### Ограничения beta

- Подписи издателя Windows и нотариального заверения Apple пока нет; macOS использует ad-hoc подпись.
- Побочные вопросы `/btw`, произвольные extension UI contributions и расширенные формы LSP пока доступны через терминальный интерфейс.
- Графические действия для сохранённых помощников и подробного вывода фоновых задач требуют следующего этапа. Их состояние и результаты core-инструментов доступны в беседе.
- Параллельные linked worktrees в разных процессах используют общий консервативный допуск Git.
