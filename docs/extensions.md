# Расширения

[Документация](README.md) · [Возможности](features.md) · [Решение проблем](troubleshooting.md)

Откройте **Настройки → Расширения**. Раздел показывает встроенные возможности и локально установленные пакеты. Слева — поиск и фильтры **Все**, **Встроенные**, **Установленные**, **Требуют внимания**. Справа — версия, состояние, ID, источник, совместимость, доверие и доступные действия. После обновления списка выбранное расширение остаётся выбранным.

## Установить пакет

1. Нажмите **Установить** и выберите **Подготовленной папки** или **ZIP**. В системном диалоге укажите папку или архив.
2. Сверьте название, ID, версию, совместимость, полный SHA-256 и список проверенных файлов. Просмотр не выполняет JavaScript пакета и не вызывает модель.
3. Оставьте галочку снятой и нажмите **Установить без доверия**, чтобы сохранить выключенный пакет. Либо явно отметьте **Доверяю именно этому содержимому и включаю расширение**, затем подтвердите.
4. Примените изменение через перезапуск после завершения задач.

Доверенный JavaScript работает с доступом процесса к файлам, сети и запуску программ. SHA-256 связывает содержимое и не подтверждает автора. Галочка доверия заранее не отмечена. **Отмена** закрывает проверку и удаляет её временную копию. Закрытие настроек также отменяет незавершённую проверку; повторный клик не создаёт вторую операцию. Если сохранение уже началось, дождитесь его фактического результата.

Пакет содержит `chisel-extension.json`, готовый `.mjs` и файлы ресурсов в корне папки/ZIP. Форматы и ограничения описаны в [общем руководстве пакетов](https://github.com/TheAsrada/ChiselCode/blob/main/docs/extensions.md).

## Состояния и применение

| Состояние | Что произошло |
| --- | --- |
| Сохранено | Выбор записан, но загрузка в текущем рабочем сеансе не подтверждена |
| Работает | Эта версия успешно активирована в текущем сеансе |
| Выключено | Возможность выключена или запрещена настройками проекта |
| Не доверено | Содержимое установлено без разрешения выполнять код |
| Ошибка | Пакет, параметры, загрузка или активация не прошли проверку; причина показана в сведениях |
| Нужен перезапуск | Сохранённый выбор или параметры отличаются от загруженных |

**Перезапустить приложение** — явное действие. Сначала дождитесь задач или остановите их, фоновые процессы и очередь сообщений. Приложение проверяет занятость перед выходом; выбранная беседа и неотправленный черновик восстанавливаются. Автоматического перезапуска и горячей выгрузки JavaScript нет.

**Включить / Выключить** меняет сохранённый выбор. Проект может запрещать внешние пакеты, но не устанавливать их или выдавать доверие. Сохранённое включение само по себе не означает, что расширение работает в текущем проекте.

## Обновление, версии и удаление

**Обновить из файла** выбирает новую папку/ZIP для того же ID. Окно проверки показывает прежнюю и новую версии, SHA-256 и содержимое. Изменённое содержимое требует отдельного доверия. Отказ, отмена до сохранения, несовместимость, повреждение и конфликт изменений сохраняют прежний выбор. При конфликте обновите список и повторите проверку с новым подтверждением.

**Версии → Проверить rollback** перепроверяет сохранённую версию и выданное ей доверие. Используемые версии отмечены отдельно и защищены от удаления. **Удалить** убирает подключение; загруженный JavaScript продолжает работать до выхода. Если файлы заняты, удаление отложено. Беседы, пользовательские файлы, настройки и другие данные сохраняются. Встроенные компоненты не удаляются как пакеты.

## Параметры

Из карточек **Анализ кода (LSP)**, **Субагенты**, **Фоновые задачи** открываются реальные формы глобальных и проектных настроек. Проектные значения наследуют глобальные и только сужают ограничения. LSP даёт Auto / Своя настройка / Выключено, выбор сервера проекта, пути к исполняемым файлам и TypeScript, аргументы запуска, проверку путей и доверие проекта. Запуск или `/lsp-restart` в беседе проходит обычную проверку разрешений.

У внешнего пакета форма показывает объявленные автором переключатели, строки, числа и списки вариантов с подписями и значениями по умолчанию. **Сохранить** проверяет и записывает глобальные значения под ID, **Сбросить** возвращает известные поля к значениям по умолчанию. Неизвестные параметры после обновления сохраняются и перечисляются. Секрет вводится скрыто; форма показывает только его наличие, сохранённое значение в неё не возвращается. Внешние параметры применяются после перезапуска. Пакет без схемы показывает «У этого расширения нет настроек».

## Версии и границы

Раздел подготовлен для Desktop 0.1.0-beta.4 с engine 0.6.30 и SDK 1.1.0. Если engine не объявляет capability управления расширениями, интерфейс показывает понятную недоступность. Существующие пакеты SDK API v1 совместимы с новым ядром.

Marketplace, установка из URLs/npm/GitHub, Memory и общий перенос внешних UI contributions в Desktop сюда не входят. [Декларативный контракт для автора](https://github.com/TheAsrada/ChiselCode/blob/main/docs/extensions/settings.md).
