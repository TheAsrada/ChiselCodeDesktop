# Решение проблем

**Ядро не запустилось или не соответствует выпуску.** Переустановите полный desktop release. Самостоятельная замена binary или SDK нарушает pinned set; глобальный chisel в PATH не исправляет встроенное ядро. Для разработки повторите sync:engine и build.

**Проект занят другим процессом.** Дождитесь завершения задачи CLI/desktop, остановите её в исходном интерфейсе или используйте отдельный clone. Linked worktrees разных процессов в beta делят common Git admission. Не удаляйте lock живого владельца. Если процесс завершился аварийно, admission проверяет PID и reclaim мёртвого владельца.

**История есть, а модель недоступна.** Выберите существующий профиль и сохранённую модель. Неизвестный/удалённый provider не меняет сохранённую историю; новая задача требует доступного подключения. Ошибки credentials исправляйте через настройки и документацию ChiselCode, сохраняя данные сессий.

**401/404/model_not_found.** Проверьте ключ, endpoint и название модели в настройках. Для OpenAI-compatible API нужен корректный `/v1` endpoint. Проверка моделей использует сохранённый профиль.

**Нет Git-панели.** Проверьте установленный Git и наличие репозитория. Обычный проект без Git можно читать/редактировать; Git/worktree-функции требуют Git.

**MCP не подключается.** Проверьте ID, HTTPS/localhost URL или отдельный executable и JSON-массив аргументов. Проверка действительно запускает сервер. Она не принимает пароль внутри URL. Сложные env/secret references и trust fingerprint настраиваются через общий CLI/config.

**Задача не меняет файл.** В Plan разрешено чтение. Dont ask отклоняет operations, требующие approval. При stale revision агент должен перечитать файл; UI не подменяет core policy.

**Обновление не найдено.** Сравните версию приложения с опубликованной beta в Releases. При отсутствии сети или ошибки updater можно установить выпуск вручную. Само наличие следующей beta не подтверждает проверку автоматической установки обновления.

В issue укажите desktop/engine version, ОС, шаги и текст ошибки. Не прикладывайте API-ключи, полный credential store или приватную историю без проверки.
