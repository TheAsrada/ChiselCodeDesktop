# Установка и обновление

[Выпуски и установщики](https://github.com/TheAsrada/ChiselCodeDesktop/releases/tag/v0.1.0-beta.2).

| Платформа | Файл |
|---|---|
| Windows x64 | `ChiselCodeDesktop-…-win-x64.exe`, мастер NSIS |
| macOS Apple Silicon | `ChiselCodeDesktop-…-mac-arm64.dmg` |
| macOS Intel | `ChiselCodeDesktop-…-mac-x64.dmg` |
| Linux x64 | `ChiselCodeDesktop-…-linux-amd64.deb` или `…-linux-x86_64.AppImage` |

Windows: запустите установщик и выберите папку. macOS: откройте DMG и перенесите приложение в Applications. Linux Debian/Ubuntu: установите локальный deb через системный менеджер пакетов. Для AppImage выдайте право исполнения и запустите файл.

В установщик включены Electron, скомпилированное ядро Bun, SDK и навыки. Пользователю не нужны Node.js/Bun/Rust. Git требуется только для Git/worktree-инструментов. Для поиска возможен штатный fallback без rg.

## Подписи первого beta

В первом выпуске нет сертификата издателя Windows и Apple notarization; macOS подписывается ad-hoc для исполнения. ОС может запросить отдельное разрешение на запуск скачанного приложения. Скачивайте из указанного репозитория; SHA256SUMS позволяет сравнить полученный файл с опубликованными байтами. Кодовая подпись издателя — отдельный шаг дальнейшего выпуска, не равнозначный контрольной сумме.

## Данные

Основная конфигурация, profiles, credentials и Session находятся в прежнем ChiselCode Home. Desktop сохраняет только собственные настройки отображения в Electron user data. Удаление/обновление приложения не должно удалять проекты или общую историю. При переносе между компьютерами ключи пересохраните штатной настройкой ChiselCode: текущий credential fallback привязан к пользовательскому окружению.

Для одновременного выполнения CLI/desktop используйте CLI 0.6.28+ с новым execution lease. Чтение прежней истории сохраняется; старый CLI не знает межпроцессного допуска и не должен параллельно изменять ту же папку.

## Обновление

В **Настройки → О приложении** можно проверить выпуск и скачать обновление. Установка блокируется, пока ядро сообщает о выполняющихся задачах или процессах. UI и engine обновляются вместе. Автоматическая загрузка/установка при закрытии отключена. В первом выпуске реальное обновление на следующий опубликованный выпуск ещё нельзя считать проверенным: остаётся также ручная установка из GitHub Releases.
